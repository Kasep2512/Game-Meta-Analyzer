# 🎮 Game Meta Analyzer & Tournament Tracker

Platform client-server untuk menganalisis pergerakan "meta" game kompetitif dan melacak hasil turnamen. Dibangun untuk mendemonstrasikan arsitektur micro-frontend/backend, manipulasi data, dan API development.

## ⚙️ Tech Stack
- **Backend:** FastAPI, SQLAlchemy, Pydantic
- **Frontend:** Streamlit, Plotly, Custom CSS/Lottie Animations
- **Data & DB:** Pandas, SQLite/MySQL
- **DevOps:** Docker, GitHub Actions

## 📁 Struktur Proyek
- `/backend`: Logika API, koneksi database, dan analisis data.
- `/frontend`: Antarmuka interaktif dan visualisasi.
- `/data`: Dataset mentah dan script seeder.

*Proyek ini sedang dalam tahap pengembangan aktif.*
